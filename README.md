# Portfolio
Team portfolio website to showcase and try out projects

## Working with Claude Code on this project

This is a manual-coding project!
The point is to practice writing the code ourselves, not to have an AI generate it. If you use Claude Code here, it
follows the rules in CLAUDE.md:

- **Allowed:** planning, brainstorming, troubleshooting if necessary , scaffolding empty templates, Review for glaring issues, and cleanup.
This is already quite generous.
- **Not allowed:** implementing features or writing application/business
  logic. Never say: "implement X" / "add X" / "build X" / "fix X".
